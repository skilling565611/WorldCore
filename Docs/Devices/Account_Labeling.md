# Account Labeling

## Safe Labels

- Use number labels such as `828 account`, `506 account`, or `4 account`.
- Do not write full email addresses in public repo notes.
- Do not store passwords or password patterns.
- Keep actual passwords only inside KeePassXC.

## Safe Status Notes

It is safe to track security status only, such as:

- Password updated.
- 2FA enabled.
- Authenticator enabled.
- Backup verified.
