# Control Prime

## Role

Control Prime is the main desktop/project machine.

## Responsibilities

- Primary coding and build system.
- Primary KeePassXC vault source.
- Uses the `Z:` drive for vault storage.
- Syncs or merges with Arctic Prime when available.

## Operating Notes

- Windows beta or preview branch updates can be disruptive.
- After major Windows updates, let Control Prime cool down and stabilize before starting builds.
- Do not store secrets in this repository.
- Do not store KeePassXC vault files, passwords, recovery codes, 2FA codes, sync codes, API tokens, or private credentials in GitHub.
