# Kevin AI Roadmap

## Purpose

Kevin AI is a future custom personal AI assistant for JacobS.

Kevin is planned to support:

- Chatbot interaction
- Project organization
- Coding assistance
- File management
- Image-to-text support
- Local/offline workflows
- WorldCore and OmniVault project memory
- Control Prime and Arctic Prime workflow support

## Core Rule

Kevin should be offline-first and avoid paid API dependence whenever possible.

## Future Roles

- Personal chatbot
- Project builder assistant
- Code helper
- Device/workflow assistant
- File organizer
- Notes/log manager
- Safe security workflow guide

## Related Systems

- WorldCore
- OmniVault
- AtlasCore
- Control Prime
- Arctic Prime
- KeepPass workflow
- PIX logs

## Long-Term Goal

Kevin may eventually become the main personal assistant for local workflows.
